## 2. Виявлені проблеми

### 🔴 Критичні (потрібне негайне виправлення)

| # | Проблема | Файл | Вплив |
|---|----------|------|-------|
| C1 | **Зламана HTML-структура** — контент між `</head>` та `<body>` | `guest/tracksall.html` | Сторінка може некоректно рендеритися |
| C2 | **Незакритий тег** — `div th:insert` без `>` | `guest/postall.html` | Можливі помилки рендерингу |
| C3 | **Порожній `<body>`** — весь контент в `<head>` | `guest/tracksall.html` | Критична помилка відображення |
| C4 | **SCSS синтаксис в CSS** — `$primary`, вкладеність `&` | `my.css`, `infoblock.css` | Стилі не працюють |
| C5 | **Контраст кольору** — #ffc800 на білому не проходить WCAG AA | Весь сайт | Доступність для людей з вадами зору |

### 🟡 Важливі (покращення UX)

| # | Проблема | Опис |
|---|----------|------|
| U1 | **Неконсистентні відступи** — `padding-top: 1px, 20px, 50px, 60px, 80px, 100px` | Різні значення на різних сторінках |
| U2 | **Inline стилі скрізь** — змішування структури та презентації | Ускладнює підтримку |
| U3 | **Закоментований код** — десятки блоків `<!-- ... -->` | Забруднює шаблони |
| U4 | **Зовнішні залежності зображень** — `bootdey.com`, `picsum.photos` | Працює тільки при наявності інтернету |
| U5 | **Немає lazy loading** — всі зображення завантажуються одразу | Повільне завантаження |
| U6 | **Порожній placeholder** — "Bottom navbar" з текстом "Bottom navbar" | Незавершений функціонал |
| U7 | **RSS кнопка без стилю** — стандартна кнопка браузера | Візуально вибивається |
| U8 | **Плейсхолдер плеєра** — "Тут буде плеєр станції" | Незавершена функція |

### 🟢 Бажані (покращення візуалу)

| # | Проблема | Опис |
|---|----------|------|
| D1 | **Банери без CSS** — порожні div, заповнюються через JS | Візуально нестабільні |
| D2 | **Фавіконка** — тільки `.ico`, немає `.png` різних розмірів | Погано відображається на мобільних |
| D3 | **Відсутні анімації** — немає hover-ефектів, transition | Статичний вигляд |
| D4 | **Немає dark mode** — тільки світла тема | Не відповідає сучасним стандартам |
| D5 | **Сторінка помилки** — базова, без брендингу | Втрачена можливість |
| D6 | **Open Graph** — є мета-теги, але немає прев'ю-генерації | Погане поширення в соцмережах |

## 3. Рекомендації

### 3.1 🏗️ Архітектура CSS

**Поточна проблема:** CSS файли розрізнені, деякі з SCSS синтаксисом, немає системи.

**Рекомендація:**
```
static/css/
├── main.css              # Об'єднати styles.css + кастомні стилі
├── components/
│   ├── navbar.css        # Навігація
│   ├── footer.css        # Футер
│   ├── cards.css         # Картки постів/треків/подкастів
│   ├── player.css        # Аудіо плеєр (об'єднати audioplayer.css)
│   ├── banners.css       # Банери (створити!)
│   └── profile.css       # Профілі (наявний)
├── pages/
│   ├── guest.css         # Гостьові сторінки
│   ├── podcast.css       # Подкасти
│   └── auth.css          # Логін/реєстрація (об'єднати my.css + register.css)
└── vendors/              # Сторонні бібліотеки
    ├── bootstrap.min.css
    ├── fontawesome.min.css
    └── toastr.min.css
```

### 3.2 🎨 Покращення кольорової схеми

**Поточна:** Gold (#ffc800) — недостатній контраст на білому.

**Рекомендована палітра:**

```css
:root {
    /* Основні */
    --color-primary:       #d4a017;  /* Темніший золотий (контраст 4.5:1+) */
    --color-primary-light:  #ffc800;  /* Поточний золотий для великих елементів */
    --color-primary-dark:   #a67c00;  /* Темний золотий для hover */

    /* Акценти */
    --color-accent:        #ff8000;  /* Помаранчевий (радіо-енергія) */
    --color-accent-light:  #ffa040;
    --color-accent-dark:   #cc6600;

    /* Нейтральні */
    --color-dark:          #1a1a2e;  /* Темно-синій (замість чорного) */
    --color-gray-dark:     #2d2d44;
    --color-gray:          #6c757d;
    --color-gray-light:    #e9ecef;
    --color-light:         #f8f9fa;
    --color-white:         #ffffff;

    /* Статуси */
    --color-success:       #28a745;
    --color-warning:       #ffc107;
    --color-danger:        #dc3545;
    --color-info:          #17a2b8;

    /* Типографіка */
    --color-text:          #212529;
    --color-text-muted:    #6c757d;
    --color-text-light:    #adb5bd;
}
```

**Обґрунтування:**
- `#d4a017` на білому = **4.6:1** ✅ проходить WCAG AA
- Темно-синій фон `#1a1a2e` замість чорного — м'якший для очей
- Помаранчевий акцент підкреслює радіо-тематику

### 3.3 📝 Типографіка

**Поточна:** Montserrat + Roboto Slab — хороший вибір.

**Рекомендації:**
1. Додати `font-display: swap` для швидшого рендерингу
2. Збільшити базовий розмір з `1rem` до `1.125rem` (18px)
3. Додати line-height `1.7` для основного тексту
4. Використати fluid typography для кращої адаптивності

```css
html {
    font-size: clamp(16px, 1.5vw, 18px);
}

body {
    font-family: 'Roboto Slab', serif;
    line-height: 1.7;
    color: var(--color-text);
}

h1, h2, h3, h4, h5, h6 {
    font-family: 'Montserrat', sans-serif;
    font-weight: 700;
    line-height: 1.3;
    color: var(--color-dark);
}
```

### 3.4 📱 Адаптивний дизайн

**Поточний:** Bootstrap grid, але з фіксованими padding-top.

**Рекомендації:**

1. **Замінити фіксовані відступи на CSS змінні:**
```css
:root {
    --navbar-height: 70px;
    --content-padding-top: calc(var(--navbar-height) + 1rem);
}

main {
    padding-top: var(--content-padding-top);
}
```

2. **Додати breakpoint-специфічні стилі:**
```css
/* Mobile first */
.card { margin-bottom: 1rem; }

/* Tablet */
@media (min-width: 768px) {
    .card { margin-bottom: 1.5rem; }
}

/* Desktop */
@media (min-width: 1200px) {
    .card { margin-bottom: 2rem; }
}
```

3. **Мобільне меню:** Додати плавну анімацію відкриття
4. **Зображення:** `max-width: 100%; height: auto;` для всіх img

### 3.5 ✨ Анімації та мікроінтеракції

### 3.6 ♿ Доступність (Accessibility)

**Пріоритетні зміни:**

1. **Контраст:** Змінити `#ffc800` → `#d4a017` для тексту
2. **ARIA-мітки:** Додати `aria-label` до всіх інтерактивних елементів
3. **Alt-тексти:** Обов'язкові для всіх динамічних зображень
4. **Фокус:** Видимий індикатор фокусу для клавіатурної навігації
5. **Skip link:** "Перейти до основного контенту"

```css
/* Focus indicator */
*:focus-visible {
    outline: 3px solid var(--color-primary);
    outline-offset: 2px;
}

/* Skip link */
.skip-link {
    position: absolute;
    top: -40px;
    left: 0;
    background: var(--color-primary);
    color: var(--color-dark);
    padding: 8px 16px;
    z-index: 10000;
    transition: top 0.3s;
}
.skip-link:focus {
    top: 0;
}
```
