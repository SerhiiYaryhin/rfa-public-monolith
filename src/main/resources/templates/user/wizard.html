Крок 1: Умови надання послуг

Правила платформи Толока:

1. Користувач несе повну відповідальність за контент, що транслюється.

2. Заборонено трансляцію контенту, що порушує законодавство України.

3. Ви погоджуєтеся на обробку персональних даних для налаштування інфраструктури.

4. Сервіс надається "як є" для некомерційних та комерційних проектів згідно обраного плану.

Крок 2: Контактна адреса

Для верифікації акаунту та підготовки контрактів необхідно вказати вашу поштову адресу.

Адреса вже додана:
Очікує схвалення Схвалено
Додати нову адресу в профайлі
Після додавання адреси, поверніться сюди та оновіть сторінку.

Завантажте скан-копію документа (паспорт або ID-картку) для ідентифікації власника станції.
