# Питання до API команди: Авторські колонки (Author Columns)

Дата: 2026-05-14

Під час аналізу вимог API_AUTHOR_COLUMNS_EXTENSIONS.md виникли такі питання:

1. **Поле "content"**: 
   - У вимогах зазначено, що поле `content` має містити JSON у форматі Editor.js. Чи потрібно нам реалізувати серверний серіалізатор для виведення цього поля, чи мобільний клієнт очікує сирий JSON-рядок, який він сам десеріалізує?
   
2. **Оптимізація зображень**:
   - Чи є у нас вже готовий ендпоінт або сервіс для динамічного ресайзу зображень, або ж нам потрібно інтегрувати новий? (У вимогах згадується `?width=w&height=h`).

3. **Кешування (ETag/Last-Modified)**:
   - Чи плануєте ви використовувати заголовки HTTP для кешування, чи достатньо буде кешування на стороні сервера (як ми зробили для дашборду)?

4. **Помилки**:
   - Чи підходить стандартна структура помилки (яку ми реалізували раніше) для статусу 404 при запиті неіснуючої колонки?
