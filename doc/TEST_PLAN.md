# План тестування оновлень RFA (Квітень 2026)

Цей документ містить перелік сценаріїв для перевірки стабільності системи після впровадження UUID-ідентифікації, пагінації та оновленого Сховища.

## 1. Тестування безпеки та ідентифікації (UUID)
- [ ] **Перевірка URL**: Переконатися, що при переході на перегляд подкасту, епізоду чи поста в адресному рядку відображається UUID (наприклад, `/podcast/view/569fef98...`), а не цифровий ID.
- [ ] **Прямий доступ**: Спробувати вручну змінити UUID в URL на неіснуючий. Система повинна видати коректне повідомлення про помилку або редірект, а не "білу сторінку".
- [ ] **Ізоляція даних**: Перевірити, чи може залогінений Користувач А отримати доступ до сторінки редагування контенту Користувача Б через підміну UUID в URL (має бути редірект або помилка доступу).

## 2. Особистий кабінет (`/user/user_page`)
- [ ] **Пагінація Постів**: Перевірити, що при натисканні на "2" у блоці постів оновлюються лише пости, а треки та подкасти залишаються на першій сторінці.
- [ ] **Пагінація Треків/Подкастів**: Аналогічна перевірка для інших блоків.
- [ ] **Відображення обкладинок**: Переконатися, що всі картки мають ілюстрації (або стандартні іконки, якщо файл відсутній).
- [ ] **Статус-баджі**: Перевірити відображення статусів модерації на картках постів.

## 3. Сховище (Storage)
- [ ] **Завантаження**: Завантажити 3-5 файлів одночасно через Dropzone. Перевірити, що сторінка автоматично перезавантажилася через 1 секунду і файли з'явилися зверху списку.
- [ ] **Копіювання UUID**: Натиснути на UUID файлу. Перевірити, чи з'явилося повідомлення "UUID скопійовано" і чи дійсно значення в буфері обміну збігається.
- [ ] **Видалення**: Видалити файл. Перевірити, чи зник він із таблиці та чи видалився фізично з диска (якщо є доступ до ФС).
- [ ] **Адмін-режим**: Зайти під адміном на `/admin/storage`. Переконатися, що видно стовпчик "Власник" і що сортування показує останні завантаження системи першими.

## 4. Життєвий цикл Подкастів
- [ ] **Створення**: Створити новий подкаст. Відразу перейти до завантаження обкладинки. Перевірити, чи зберігся зв'язок.
- [ ] **Категорії iTunes**: Змінити категорії подкасту, зберегти, перезавантажити сторінку. Перевірити, чи залишилися обрані категорії на місці.
- [ ] **Видалення епізоду**:
    - Тест А: Видалити епізод, відмовившись від видалення файлу. Перевірити, що файл залишився у "Сховищі".
    - Тест Б: Видалити епізод разом із файлом. Перевірити, що файл зник і зі "Сховища".
- [ ] **Видалення каналу**: Видалити весь подкаст. Перевірити, чи видалилися всі його епізоди та обкладинка каналу.

## 5. Сумісність та редіректи
- [ ] **Старі посилання**: Перейти вручну за адресою `/creater/store/0`. Система повинна коректно відобразити нове сховище (спрацював alias).
- [ ] **Компіляція**: Виконати `./gradlew compileJava` для впевненості, що всі залежності на місці.

## 6. Email-інструмент (Адмін)
- [ ] **Пошта**: Спробувати відправити тестовий лист через `/admin/email_sender`. Перевірити отримання та коректність підстановки імені користувача.
