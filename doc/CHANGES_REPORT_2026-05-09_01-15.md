# Звіт про виконані зміни та оптимізації проекту (2026-05-06 — 2026-05-09)

У цьому документі детально описано всі технічні зміни, внесені в ході поточної сесії розробки. Роботи охопили оптимізацію продуктивності, редизайн інтерфейсів, покращення SEO/соціальних прев'ю та виправлення критичних помилок.

## 1. Оптимізація продуктивності (Data Model)
Було проведено глибокий аналіз JPA-моделі, що виявив причини повільного завантаження сайту (проблема N+1 та надлишкове завантаження даних).

*   **Перехід на Lazy Loading:** Усі критичні зв'язки `@OneToMany` та `@ManyToOne` у класах `Clientdetail`, `Post`, `Track`, `Album`, `Store` та `PodcastItem` переведені з `FetchType.EAGER` на `FetchType.LAZY`.
*   **Результат:** Радикальне зменшення кількості автоматичних SQL-запитів при завантаженні профілів та списків. Споживання пам'яті сервером оптимізовано.
*   **Документація:** Створено детальний план подальшої оптимізації: `doc/2026-05-06_OPTIMIZATION_PLAN.md`.

## 2. SEO та соціальні мережі (Open Graph & Twitter Cards)
Проведено повний аудит та уніфікацію метаданих для коректного відображення посилань у Facebook, Telegram та Twitter.

*   **Рефакторинг фрагментів:** У `common.html` всі фрагменти метаданих уніфіковані з використанням `th:content` замість застарілого `th:attr`.
*   **Динамізація доменів:** Впроваджено `GlobalModelAttributes` (`ControllerAdvice`), що передає `siteUrl` у всі шаблони. Це усунуло проблему захардкоджених посилань на тестових серверах.
*   **Нові метадані:** Додано OG-теги для всіх сторінок-архівів (Усі новини, Подкасти, Треки, Хаб авторів).
*   **Виправлення скрейпінгу:** Оновлено `robots.txt` для дозволу доступу роботам Facebook (`facebookexternalhit`), що усунуло помилку 403 при перевірці посилань.

## 3. Редизайн та функціонал Кабінету Автора
Форми керування контентом повністю перероблені для кращого UX та стабільності.

*   **Треки та Альбоми:**
    *   Повний редизайн форм редагування на базі Bootstrap 5 та шрифту Inter.
    *   **Асинхронне завантаження:** Реалізовано механізм AJAX-завантаження аудіофайлів та обкладинок з індикаторами прогресу.
    *   **Автоматизація:** При заміні файлу старі версії тепер автоматично видаляються зі сховища.
    *   **Медіа-функції:** Додано вбудовані аудіоплеєри та миттєве прев'ю зображень без перезавантаження сторінки.
*   **Виправлення логіки:** Керування треками переведено на використання UUID, що зробило посилання для видалення та публікації стабільними.

## 4. Конвертер контенту (TinyMCE -> Editor.js)
Розширено можливості вбудованого конвертера для безболісної міграції старих постів.

*   **Нові блоки:** Додано підтримку цитат (`blockquote`), роздільників (`hr`), таблиць (`table`) та YouTube-відео (`embed`).
*   **Sanitization:** Впроваджено метод `cleanInlineHtml` для ретельного очищення тексту від сміттєвих стилів MS Word/TinyMCE при збереженні базового форматування.
*   **Надійність:** Виправлено помилки в JavaScript-коді редактора, зокрема конфлікти з модальними вікнами Bootstrap.

## 5. Технічні виправлення та стабільність
*   **Виправлення пагінації:** У Сховищі та Адмін-панелі усунуто помилки 404. Контролери переведені на `@RequestParam` для сумісності з універсальним фрагментом пагінації. Додано редиректи для підтримки старих посилань.
*   **Podcast Episode:** Виправлено критичну помилку `TemplateProcessingException` на сторінці епізоду подкасту шляхом коректної передачі `storeService` та оптимізації доступу до властивостей об'єкта.
*   **Код-стайл:** Виправлено відсутні імпорти, що заважали успішній збірці проекту через Gradle.
