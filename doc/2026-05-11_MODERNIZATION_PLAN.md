# План модернізації проекту RFA (Травень 2026)

На основі успішного впровадження універсального модуля завантаження та оновлення системи обробки медіа, розроблено наступний план поетапної модернізації системи.

## Етап 1: Уніфікація медіа-менеджменту (Media Centralization)
**Мета:** Повне переведення всіх модулів на `StoreItemController` та очищення застарілого коду.

1.  **Міграція Постів (Новин):** 
    *   Заміна завантажувача головної ілюстрації на універсальний.
    *   Оновлення JS у `editpost.html`.
2.  **Міграція Музичного розділу:**
    *   Переведення завантаження треків (`.mp3`) та обкладинок альбомів на універсальний REST API.
    *   Очищення `CreaterDropPostFileController`.
3.  **Міграція Профілів:**
    *   Оновлення форми редагування профілю для використання універсального завантажувача фото.
4.  **Автоматизація очищення сховища:**
    *   Впровадження логіку "заміни": при завантаженні нової ілюстрації для сутності, старий файл автоматично видаляється або позначається як видалений.

## Етап 2: Модернізація контенту та редакторів
**Мета:** Відмова від TinyMCE (HTML) на користь блочного редактора Editor.js (JSON) для всіх типів контенту.

1.  **Уніфікація сутності Post та AuthorArticle:** 
    *   Приведення структури збереження контенту до єдиного формату JSON.
2.  **Міграція Постів на Editor.js:**
    *   Розробка конвертора старого HTML у блоки Editor.js.
    *   Оновлення фронтенду для рендерингу блоків.
3.  **Розширення функціоналу Editor.js:**
    *   Додавання специфічних плагінів: аудіоплеєр всередині тексту, вставка подкастів, спеціальні галереї.

## Етап 3: Рефакторинг Архітектури (Core Optimization)
**Мета:** Покращення продуктивності та стабільності backend-частини.

1.  **Консолідація сервісів:**
    *   Об'єднання `FilesService`, `StoreFileImplementation` та допоміжних утиліт у єдину, добре протестовану медіа-бібліотеку.
2.  **Оптимізація бази даних:**
    *   Впровадження індексів для прискорення пошуку медіа-файлів за типом та датою.
    *   Рефакторинг репозиторіїв з використанням сучасних методів Spring Data.
3.  **Розширення API для Мобільних додатків:**
    *   Забезпечення того, щоб всі нові REST-ендпоінти були готові до використання зовнішніми клієнтами (iOS/Android).

## Етап 4: Візуальне оновлення та UI/UX
**Мета:** Приведення всього сайту до стилістики "Авторської колонки" (Inter + Lora).

1.  **Компонентна бібліотека:**
    *   Створення єдиних фрагментів Thymeleaf для карток постів, треків та подкастів.
2.  **Покращення адаптивності:**
    *   Перегляд всіх форм редагування для зручної роботи з мобільних пристроїв.
3.  **Інтерактивність:**
    *   Більше асинхронних операцій (без перезавантаження сторінок) через Fetch API.

---
**Наступний крок:** Міграція модуля "Пости" на універсальний завантажувач медіа.
