# Технічне завдання: Модуль "Авторська колонка"

## 1. Загальні відомості
Модуль призначений для створення персоналізованих розділів для авторів (журналістів, блогерів, експертів), де вони можуть публікувати свої аналітичні матеріали, статті та замітки. 

## 2. Ролі користувачів
- **Користувач**: Зареєстрований відвідувач, який може читати колонки та подавати запит на отримання статусу "Автор".
- **Автор**: Користувач з дозволом на створення власної колонки та написання статей.
- **Адміністратор**: Керує запитами на створення колонок, модерирує статті, призначає ролі.

## 3. Функціональні вимоги

### 3.1. Запит на авторську колонку
- У профілі користувача додається кнопка "Стати автором".
- Форма запиту містить:
    - Тематика майбутньої колонки.
    - Коротке резюме/портфоліо.
    - Посилання на приклади робіт.
- Статус запиту: `PENDING`, `APPROVED`, `REJECTED`.

### 3.2. Створення та редагування контенту (Editor.js)
- Використання **Editor.js** як основного інструменту написання статей.
- Підтримка блоків: `Header`, `Paragraph`, `List`, `Image`, `Quote`, `Embed` (YouTube/Soundcloud).
- Функція автозбереження чернетки.
- Можливість завантаження головної ілюстрації статті.

### 3.3. Життєвий цикл статті
1. **Чернетка**: Видно тільки автору.
2. **На модерації**: Після натискання "Опублікувати" стаття потрапляє до Адміністратора.
3. **Опубліковано**: Стаття доступна публічно після схвалення Адміністратором.
4. **Відхилено**: Стаття потребує виправлень (з коментарем модератора).

### 3.4. Адміністрування (Панель адміністратора)
- Список усіх запитів на авторство з можливістю перегляду деталей.
- Інтерфейс модерації статей:
    - Перегляд чернетки у фінальному вигляді.
    - Кнопки "Схвалити", "Надіслати на доопрацювання", "Видалити".
    - Поле для коментаря автору при відхиленні.
- Керування списком авторів (можливість відкликати статус автора).

## 4. Технічні вимоги та Стеку
- **Frontend**: Bootstrap 5 для адаптивної верстки.
- **Editor**: Editor.js (збереження даних у форматі JSON у БД).
- **Backend**: Java (Spring Boot).
- **База даних**: PostgreSQL (новий Entity `AuthorColumn` та `AuthorArticle`).

## 5. UI/UX Дизайн (Bootstrap)
- **Головна сторінка колонок**: Сітка карток авторів з останніми публікаціями.
- **Сторінка колонки**: Профіль автора (фото, біографія) + список усіх його статей.
- **Сторінка статті**: Чистий текстовий дизайн (Typography-focused) з великим заголовком та зручним читанням на мобільних пристроях.

## 6. Додаткові рекомендації (Розширення)
- **Slug-посилання**: Людиночитані URL (наприклад, `/columns/ivan-ivanov/naslova-statti`).
- **Система сповіщень**: Повідомлення автору в кабінет/email про зміну статусу його публікації.
- **Коментарі**: Можливість підключення обговорень до статей авторської колонки.
- **Аналітика**: Відображення кількості переглядів кожної статті для автора та адміна.
