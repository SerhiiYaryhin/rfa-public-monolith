# Фронтенд та користувацький інтерфейс RFA

Фронтенд проекту побудований на поєднанні серверного рендерингу (SSR) та інтерактивних клієнтських компонентів.

## 1. Технологічний стек
- **Шаблонізатор:** Thymeleaf (Spring Standard Dialect + Security Extras).
- **CSS-фреймворк:** Bootstrap 5.3.
- **JS-бібліотеки:** jQuery (базова логіка), SockJS/STOMP (чати), Editor.js (редактор статей), Dropzone.js (завантаження файлів).

## 2. Структура шаблонів
Всі шаблони знаходяться в `src/main/resources/templates/`.
- `fragments/`: Багаторазові компоненти (навігація `navbarUniverse`, футер, системні повідомлення).
- `admin/`: Панелі керування для адміністраторів (користувачі, станції, модерація).
- `author/`: Кабінет автора та інструменти написання статей.
- `store/`: Інтерфейс Глобального Сховища.
- `user/`: Особистий кабінет пересічного користувача.

## 3. Ключові клієнтські рішення

### 3.1. Редактор статей (Editor.js)
Використовується в `author/editor.html` для створення насиченого контенту.
- **Конфігурація:** Підтримує заголовки, списки, зображення, цитати та вставки (embeds).
- **Логіка:** Дані зберігаються як JSON. В проекті реалізовано автоматичне завантаження зображень через `AuthorRestController`.

### 3.2. Медіа-плеєр
Реалізовано два типи плеєрів:
- **AudioPlayer.js:** Стандартний плеєр для прослуховування треків у списках.
- **RFAPodcastPlayer.js:** Спеціалізований плеєр для подкастів з підтримкою черги відтворення.

### 3.3. Реальний час (WebSockets)
Файл `chat.js` відповідає за інтерактивну взаємодію в реальному часі.
- Підключення до `/rfachat`.
- Відображення нових повідомлень та лічильників непрочитаного в набарі.

### 3.4. Завантаження файлів
- **Dropzone.js:** Інтегрований у `fileupload.html`. Дозволяє завантажувати великі файли з візуальною індикацією прогресу та автоматичним оновленням списку після завершення.

## 4. Стилі та дизайн
- **Тема:** Темний набар (`navbar-dark bg-dark`) з акцентними кольорами для різних типів контенту:
    - Зелений — Подкасти.
    - Синій — Статті.
    - Жовтий — Музика/Треки.
- **Файли:**
    - `MyStyle.css`: Глобальні перевизначення Bootstrap.
    - `profile.css`: Оформлення карток в особистому кабінеті.
    - `styles.css`: Стилі публічної частини (Landing Page).

## 5. Адаптивність
Весь інтерфейс спроектований за принципом mobile-first. Навігаційна панель автоматично згортається в "бургер-меню" на мобільних пристроях, а таблиці даних замінюються на картки (через Bootstrap grid).
