# Перевірка збереження нового поста

## Процес створення нового поста

1. **Створення поста**:
   - Коли користувач переходить за посиланням `/creater/editpost/0`, викликається метод `getCreaterEditPost`
   - У цьому методі перевіряється, чи `uuidPost.equals("0")`
   - Якщо так, то створюється новий об'єкт `Post()` з автоматичною генерацією UUID в моделі:
     ```java
     private String uuid= UUID.randomUUID().toString();
     ```

2. **Збереження поста**:
   - При відправленні форми викликається метод `postCreaterEditPost`
   - Якщо `uuidPost.equals("0")`, то створюється новий об'єкт `Post()` зі статусом `POSTSTATUS_REDY`
   - Дані з форми зберігаються в об'єкт поста
   - Викликається `postService.SavePost(post)` для збереження в базі даних

3. **Встановлення ілюстрації**:
   - При виборі ілюстрації викликається метод `SetPostMainImage`
   - Якщо пост ще не був збережений (uuid="0"), це було виправлено в `CreaterStoreController`
   - Після встановлення ілюстрації відбувається перенаправлення на `/creater/editpost/` з актуальним UUID поста

## Висновок

Процес створення та збереження нового поста реалізований належним чином:
- Автоматична генерація UUID при створенні об'єкта
- Коректна обробка випадку, коли uuid="0" (новий пост)
- Збереження поста в базі даних
- Можливість встановлення ілюстрації для нового поста
- Перенаправлення на сторінку редагування з актуальним UUID

Усі виправлення, необхідні для коректної роботи процесу створення нового поста, вже внесені в систему.
