# Історія змін проекту RFA

## [2026-04-22] Безпечна передача даних у JavaScript (Thymeleaf 3.1)
- **Виправлено**: Помилка `TemplateProcessingException` у `mainstore.html` та `admin.html`. Проблема виникала через некоректну конкатенацію рядків у атрибуті `onclick`.
- **Рішення**: Впроваджено використання `data-uuid` атрибутів для безпечної передачі UUID файлів у JavaScript-функції копіювання. Це відповідає сучасним стандартам безпеки Thymeleaf.
- **Стабільність**: Усунуто причину відмови рендерингу сторінок сховища.
