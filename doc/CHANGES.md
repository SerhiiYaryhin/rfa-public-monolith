# Історія змін проекту RFA

## [2026-04-20] Покращення роботи з ілюстраціями постів та валідація публікації
- **Новий функціонал**: Впроваджено обов'язкову перевірку наявності головної ілюстрації перед подачею посту на модерацію.
- **Автоматизація**: 
    - Реалізовано автоматичне призначення завантаженої картинки як головної ілюстрації посту відразу після завантаження.
    - Автоматичний редірект назад до форми редагування після вибору або завантаження зображення.
- **Бекенд**: 
    - Додано серверу валідацію статусу `POSTSTATUS_REQUEST`.
    - Оновлено `CreaterDropPostFileController` для повернення UUID файлу.
- **Frontend**:
    - Оновлено `editpost.html`: додано блок попереднього перегляду ілюстрації та вибір статусів.
    - Оновлено `setpostmainpicture.html`: модернізовано інтерфейс вибору та завантаження.

## [2026-04-20] Рестайлінг інтерфейсу Творця (Creater)
- **Покращено**: Повністю оновлено вигляд таблиць у розділі "Контент" (Треки, Альбоми, Пости).
- **Frontend (`fragments/creater.html`)**:
    - Впроваджено використання **Bootstrap Badges** для статусів модерації.
    - Додано **іконки FontAwesome** для всіх основних дій.
    - Реалізовано **btn-group** для компактного розміщення інструментів керування.
    - Додано візуальне підсвічування рядків залежно від статусу публікації.
- **Статистика**: У списку постів тепер чітко відображається кількість переглядів та дати життєвого циклу публікації.
