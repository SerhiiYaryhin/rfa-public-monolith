# Історія змін проекту RFA

## [2026-04-21] Відновлення функціоналу списку постів
- **Виправлено**: Помилка 404 при переході на сторінку `/creater/posts/0`. Метод `getCreaterPosts` був випадково видалений під час попереднього рефакторингу. Функціонал повністю відновлено.
- **Покращено**: Проведено коректне іменування методів у `PostController.java` для уникнення конфліктів та покращення читабельності коду.

---

## [2026-04-20] Виправлення NullPointerException при призначенні ілюстрації
- **Виправлено**: Критична помилка 500 (NPE) у методі `SetPostMainImage` класу `PostController.java`. Додано перевірки на `null` для об'єктів `Post` та `Store`, що запобігає падінню системи у разі затримок у базі даних або невірних UUID.
- **Логування**: Додано логування помилок призначення ілюстрацій для кращого дебагу.

---

## [2026-04-20] Глобальний перехід на UUID для ідентифікації постів
- **Архітектура**: Повністю відмовилися від використання числових `id` (Long) у публічних посиланнях та контролерах постів на користь `uuid` (String). Це підвищує безпеку та надійність системи.
- **Виправлено**: Проблема, при якій нова ілюстрація не відображалася відразу після вибору. Тепер редірект будується на базі UUID, що гарантує коректне завантаження актуальних даних Hibernate.
