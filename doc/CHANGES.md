# Історія змін проекту RFA

## [2026-04-20] Глобальний перехід на UUID для ідентифікації постів
- **Архітектура**: Повністю відмовилися від використання числових `id` (Long) у публічних посиланнях та контролерах постів на користь `uuid` (String). Це підвищує безпеку та надійність системи.
- **Виправлено**: Проблема, при якій нова ілюстрація не відображалася відразу після вибору. Тепер редірект будується на базі UUID, що гарантує коректне завантаження актуальних даних Hibernate.
- **Бекенд**: 
    - Рефакторинг `PostController.java` та `AdminPosts.java`: всі `@PathVariable` змінено на `uuidPost`.
    - `PostService.java`: перейменовано метод `GetByUiid` -> `GetPostByUuid` та виправлено друкарську помилку.
- **Frontend**:
    - Оновлено посилання у всіх шаблонах (`editpost.html`, `setpostmainpicture.html`, `admin.html`, `creater.html`).
    - Форма редагування тепер відправляється за адресою `/creater/editpost/{uuid}`.

---

## [2026-04-20] Виправлення NullPointerException при призначенні ілюстрації
- **Виправлено**: Критична помилка 500 (NPE) у методі `SetPostMainImage`. Додано перевірки на `null` для об'єктів `Post` та `Store`.
- **Логування**: Додано логування помилок призначення ілюстрацій.
