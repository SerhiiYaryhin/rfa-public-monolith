# Історія змін проекту RFA

## [2026-04-20] Виправлення NullPointerException при призначенні ілюстрації
- **Виправлено**: Критична помилка 500 (NPE) у методі `SetPostMainImage` класу `PostController.java`. Додано перевірки на `null` для об'єктів `Post` та `Store`, що запобігає падінню системи у разі затримок у базі даних або невірних UUID.
- **Логування**: Додано логування помилок призначення ілюстрацій для кращого дебагу.

---

## [2026-04-20] Виправлення відображення ілюстрацій постів та стабілізація
- **Виправлено**: Проблема, при якій зміни головної ілюстрації посту адміністратором не відображалися на головній сторінці. 
- **Архітектура**: Видалено жорстко прописані посилання на зовнішній домен. Тепер використовуються відносні шляхи `/store/content/`.
- **Frontend**: Оновлено `infoblock.html`, `mediahub.html` та `guest/postall.html`.
- **Стабільність**: Виправлено помилку компіляції в `PostController.java` (статичний імпорт `EPostStatus`).

## [2026-04-20] Покращення роботи з ілюстраціями постів та валідація публікації
