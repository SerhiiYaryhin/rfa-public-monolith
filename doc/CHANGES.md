# Історія змін проекту RFA

## [2026-04-22] Публічна модерація, пагінація та покращене аудіо
- **Модерація контенту**: Впроваджено фільтрацію для публічних сторінок. Тепер треки, пости та подкасти відображаються лише після схвалення адміністратором (`apruve = true`).
- **Аудіо-стрімінг**: Реалізовано підтримку перемотки аудіо (HTTP Range) через `FileSystemResource`. Це забезпечує стабільну роботу плеєра в усіх браузерах.
- **Адміністрування**:
    - Додано пагінацію для списків треків та постів у панелі адміністратора.
    - Створено новий розділ "Керування подкастами" для глобальної модерації каналів.
- **UI/UX**: 
    - Оновлено дизайн таблиць модерації з використанням інтерактивних перемикачів статусу.
    - Оновлено головну сторінку та список постів для коректної роботи пагінації.
