# Історія змін проекту RFA

## [2026-04-22] Покращений діалог видалення файлів (Обнулити/Видалити/Відмовитися)
- **UI**: На сторінці підтвердження видалення файлу (`confirm_delete.html`) додано три чіткі дії:
    - **Відмовитися**: Скасування будь-яких дій та повернення до сховища.
    - **Обнулити посилання**: Від'єднання файлу від усіх об'єктів (подкастів, постів тощо) без його фізичного видалення.
    - **Видалити файл**: Повне видалення файлу з сервера після обнулення посилань.
- **Бекенд**: Метод `confirmDeleteStoreItem` тепер підтримує прапор `onlyDetach` для збереження файлу при очищенні зв'язків.
