## [2026-04-21] Виправлення відображення існуючих обкладинок подкастів
- **Виправлено**: Проблема, при якій на сторінках завантаження обкладинок не відображався список уже існуючих зображень користувача. Синхронізовано імена атрибутів моделі між контролером та шаблонами (`podcastImageList` -> `storeList`).
- **Покращено**: Тепер на сторінці вибору обкладинки відображаються всі завантажені користувачем ілюстрації, а не лише обмежений список.
