# Історія змін проекту RFA

## [2026-04-20] Виправлення помилок у Поштовому офісі та стабілізація
- **Виправлено**: Критична помилка `TemplateProcessingException` у `admin/email_sender.html`. Поле `u.username` замінено на коректне відображення імені з `clientdetail` або `email` користувача, оскільки сутність `Users` не містить поля `username`.
- **Покращено**: Логіка відображення списку користувачів у поштовому хабі: тепер відображаються ПІБ користувача для зручнішої ідентифікації при виборі отримувачів.
- **Стабільність**: Усунуто потенційні проблеми при роботі з користувачами, у яких не заповнений профіль (`null-safe` перевірки).

## [2026-04-19] Рефакторинг завантаження та система модерації треків

### Огляд
Було проведено комплексний рефакторинг процесу завантаження аудіофайлів та впроваджено повноцінну систему модерації. Створено універсальний інструмент "Поштовий офіс" для гнучкого спілкування з користувачами.

### Внесені зміни

#### 1. Бекенд (Java / Spring Boot)
*   **`AdminEmailController` (Новий)**: Хаб для керування розсилками. Доступний для ролей ROLE_ADMIN, ROLE_MODERATOR, ROLE_EDITOR.
*   **`EmailSenderService`**: Додано функціонал динамічного зчитування шаблонів та метод `sendRawHtmlEmail`.
*   **`AdminTracks` & `AdminService`**: Реалізовано модерацію, каскадне видалення та перемикання статусів публікації.
*   **`CreaterService`**: Оновлено для підтримки асинхронного завантаження через UUID.

#### 2. Фронтенд (Thymeleaf / JavaScript)
*   **`admin/email_sender.html` (Новий)**: Інтерфейс із вибором отримувачів та інтеграцією **TinyMCE**.
*   **`trackupload.html`**: Новий двоетапний інтерфейс завантаження треків.
*   **`admin/tracks.html`**: Панель керування медіатекою з перемикачами статусів.

#### 3. Безпека та Стабільність
*   **UUID**: Впроваджено ідентифікацію через `uuid` для публічних посилань.
*   **Null-Safety**: Додано захист від порожніх об'єктів у шаблонах.
*   **Конфігурація**: Налаштовано `mail.from` у всіх профайлах.

### Результат
Проект отримав завершений цикл управління медіа-контентом та потужний інструмент комунікації з користувачами.
