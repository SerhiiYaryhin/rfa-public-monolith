# Історія змін проекту RFA

## [2026-04-22] Відновлення відтворення треків та стабілізація плеєра
- **Виправлено**: Неможливість відтворення треків на головній сторінці. Причина була у використанні застарілого `storeuuid` замість `storeitem.uuid` у шаблоні `mediahub.html`.
- **Фронтенд**: Оновлено фрагмент `lasttrecks` — тепер JavaScript отримує актуальний UUID об'єкта `Store`.
- **Бекенд**: Посилено `StoreSiteController`:
    - Додано логування відсутності файлів на диску.
    - Впроваджено автоматичне встановлення MIME-типу (`audio/mpeg`), якщо він відсутній у базі.
- **Стабільність**: Забезпечено коректну роботу `audio-player` при кліках на список треків.
