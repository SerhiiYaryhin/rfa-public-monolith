# Історія змін проекту RFA

## [2026-04-20] Виправлення відображення ілюстрацій постів та стабілізація
- **Виправлено**: Проблема, при якій зміни головної ілюстрації посту адміністратором не відображалися на головній сторінці. 
- **Архітектура**: Видалено жорстко прописані (hardcoded) посилання на зовнішній домен `https://rfa.toloka.media/` у шаблонах. Тепер використовуються відносні шляхи `/store/content/`, що дозволяє коректно відображати ілюстрації на локальних та тестових серверах.
- **Frontend**:
    - `infoblock.html`: Оновлено фрагмент `postcardtile` для використання локальних шляхів.
    - `mediahub.html`: Замінено випадкові зображення `picsum.photos` на реальні ілюстрації постів зі сховища.
    - `guest/postall.html`: Виправлено шляхи до зображень у каталозі новин.
- **Стабільність**: Виправлено помилку компіляції в `PostController.java` (додано статичний імпорт `EPostStatus`).
