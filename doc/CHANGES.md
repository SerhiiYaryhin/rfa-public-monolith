# Історія змін проекту RFA

## [2026-04-23] Реалізація потокового аудіо (Streaming з ResourceRegion)
- **Архітектура**: Повернуто та вдосконалено логіку потокового мовлення. Замість віддачі файлу цілком впроваджено використання `ResourceRegion`.
- **Функціонал**: Забезпечено повноцінну підтримку HTTP Range запитів, що дозволяє плеєрам завантажувати аудіо частинами та виконувати миттєву перемотку.
- **Стабільність**: Усунено помилки типів у контролері `StoreSiteController` при роботі з заголовками.
