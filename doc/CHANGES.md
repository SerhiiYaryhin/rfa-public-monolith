# Звіт про зміни в системі завантаження та модерації треків

## Огляд
Було проведено комплексний рефакторинг процесу завантаження аудіофайлів та впроваджено повноцінну систему модерації. Останнім етапом стало створення універсального інструменту "Поштовий офіс" для гнучкого спілкування з користувачами.

## Внесені зміни

### 1. Бекенд (Java / Spring Boot)

*   **`AdminEmailController` (Новий)**:
    *   Хаб для керування розсилками. Доступний для ролей ROLE_ADMIN, ROLE_MODERATOR, ROLE_EDITOR.
    *   Підтримує індивідуальні та масові розсилки.
*   **`EmailSenderService`**:
    *   Додано функціонал динамічного зчитування шаблонів із папки `templates/mail/`.
    *   Реалізовано метод `sendRawHtmlEmail` для відправки листів після візуального редагування.
*   **`CreaterService` & `AdminService`**:
    *   Оновлено методи для роботи з повними списками треків та користувачів.

### 2. Фронтенд (Thymeleaf / JavaScript)

*   **`admin/email_sender.html` (Новий)**:
    *   Інтерфейс із вибором отримувачів (чекбокси).
    *   Кнопки швидкого вибору груп користувачів (Всі, Творці).
    *   Інтеграція **TinyMCE** для візуального редагування тіла листа перед відправкою.
    *   AJAX-завантаження контенту шаблонів.
*   **`admin/tracks.html`**:
    *   Додано кнопку "Повідомити автора", яка веде до поштового хабу з предзаповненими даними.
*   **`navbar.html`**:
    *   Пункт "Пошта" додано в меню для всіх рівнів адміністрації.

### 3. Безпека та Стабільність

*   **Конфігурація**: Параметр `mail.from` синхронізовано у всіх профайлах.
*   **Null-Safety**: Додано захист від порожніх об'єктів медіа-сховища.
*   **Права доступу**: Розширено доступ до поштових інструментів для модераторів та редакторів.

## Результат
Адміністрація проекту отримала потужний інструмент для комунікації. Тепер будь-яка дія (схвалення треку, видалення або загальне оголошення) може супроводжуватися персоналізованим листом, зміст якого можна відредагувати "на льоту".
