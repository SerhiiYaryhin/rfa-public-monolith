# Завдання для серверної команди: API для окремого поста (Post)

**Назва завдання:** Реалізація ендпоінту для отримання окремого поста за ID

## Опис
Наразі мобільний застосунок отримує пости лише через спискові ендпоінти (пагінацію). Для реалізації глибоких посилань (deep linking) та оптимізації роботи з контентом нам необхідно мати можливість завантажити повну інформацію про конкретний пост за його унікальним ідентифікатором.

## Новий ендпоінт
*   **Метод:** `GET /api/v1/posts/{id}`
*   **Опис:** Повертає об'єкт поста у повному форматі.
*   **Параметри:**
    *   `id` (path): Унікальний ідентифікатор поста (UUID або String).

## Очікувана структура відповіді (JSON):
```json
{
  "id": "string",
  "title": "string",
  "imageUrl": "string",
  "createdAt": "ISO8601",
  "summary": "string",
  "content": "string" 
}
```
*Примітка: поле `content` має містити JSON-рядок у форматі Editor.js (або існуючий формат контенту).*

## Технічні вимоги:
*   **Доступ:** Публічний (permitAll).
*   **Обробка помилок:** Повертати `404 Not Found`, якщо пост не знайдено, у стандартному форматі помилок проекту.
*   **Оптимізація:** Підтримка динамічного ресайзу зображень (якщо реалізовано на бекенді).

## Пріоритет: Середній
**Причина:** Потрібно для реалізації функціоналу ділення статтями та глибоких посилань.
