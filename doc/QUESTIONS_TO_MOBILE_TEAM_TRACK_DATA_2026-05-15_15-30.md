# Уточнення вимог до API: Треки (Tracks)

Дата: 2026-05-15 15:30

## 1. Мета
Уточнити вимоги до структури об'єкта `Track` та визначити специфікацію для отримання детальної інформації про конкретний трек.

## 2. Структура об'єкта `Track`

Кожен об'єкт `Track` повинен мати наступну структуру для використання в ендпоінтах `/dashboard`, `/tracks` та `/tracks/{id}`:

### 2.1 JSON Схема
```json
{
  "id": "string",
  "title": "string",         // Обов'язкове поле
  "artist": "string",        // Обов'язкове поле
  "streamUrl": "string",     // Обов'язкове поле (для live-потоків)
  "genre": "string",         // Опціональне поле
  "imageUrl": "string",      // Опціональне поле (URL до зображення)
  "description": "string",   // Опціональне поле
  "fileUrl": "string",       // Опціональне поле (для відтворення файлів)
  "createdAt": "ISO8601"
}
```

## 3. Нові ендпоінти

### 3.1 Отримання детальної інформації про трек
*   **Метод:** `GET /api/v1/tracks/{id}`
*   **Опис:** Повертає повний об'єкт треку (включаючи повний опис та посилання для відтворення).
*   **Параметри:**
    *   `id` (path): Унікальний ідентифікатор треку.
*   **Response (200 OK):** Об'єкт `Track` згідно зі схемою 2.1.
*   **Response (404 Not Found):** Повертається, якщо трек з даним ідентифікатором відсутній.

## 4. Ключові уточнення

### 4.1 Типи аудіо
*   **`streamUrl`**: Обов'язкове поле для потокового відтворення (радіо).
*   **`fileUrl`**: Опціональне поле для відтворення статичних файлів (MP3 тощо).

### 4.2 Обов'язковість полів
*   **Обов'язкові:** `title`, `artist`, `streamUrl`.
*   **Опціональні:** `genre`, `imageUrl`, `description`, `fileUrl`.
    *   *Примітка щодо `imageUrl`:* Повинно містити посилання виключно на графічний файл. Якщо обкладинка відсутня, поле має бути порожнім або `null`.

### 4.3 Уніфікація ендпоінтів
Вимоги актуальні для:
*   `GET /api/v1/dashboard`
*   `GET /api/v1/tracks`
*   `GET /api/v1/tracks/{id}`

## 5. Пріоритет: Високий
**Причина:** Коректна структура даних та наявність детального ендпоінту є критично важливими для стабільної роботи плеєра та підтримки deep linking.
