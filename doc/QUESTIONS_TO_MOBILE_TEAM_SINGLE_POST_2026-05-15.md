# Питання до API команди: Авторські колонки (Author Columns)

Дата: 2026-05-14

Під час аналізу TASK_BACKEND_SINGLE_POST_API.md виникли такі питання:

1. **Поле "content"**: 
   - Вимоги вказують на поле `content`. Чи повинно воно містити саме "сирий" JSON-рядок Editor.js (як ми зробили для колонок), чи це має бути вже оброблений/рендерізований HTML-код?

2. **Зв'язаний контент**:
   - Чи потрібно в детальному об'єкті поста повертати дані про автора (об'єкт `AuthorDto`) або список схожих постів/коментарів до цього поста? Якщо так, чи є вимоги до формату цих вкладених об'єктів?

3. **Коди відповідей**:
   - Чи потрібно нам повертати якісь специфічні метадані (наприклад, кількість переглядів, статус публікації) у відповіді на запит детальної інформації, чи обмежуємось виключно полями з документації?

4. **Оптимізація**:
   - Як клієнт планує передавати параметри для ресайзу зображень (якщо ми їх реалізуємо), якщо в об'єкті `Post` ми віддаємо лише рядок `imageUrl`?
