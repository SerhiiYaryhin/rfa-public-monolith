# Завдання для серверної команди: Авторські колонки (Public Access)

**Назва завдання:** Відкрити публічний доступ до ендпоїнтів авторських колонок

## Опис
Наразі ендпоїнти для роботи з авторськими колонками потребують авторизації (`Bearer Token`). Оскільки дані про авторські статті є публічними, нам необхідно прибрати вимогу авторизації для наступних методів API:

## Перелік ендпоїнтів для зміни:
1. `GET /api/v1/columns` (включаючи пагінований список)
2. `GET /api/v1/columns/{id}`

## Технічні вимоги:
*   **Security:** Встановити рівень доступу `Public` (permitAll) для вказаних маршрутів у конфігурації безпеки (Spring Security).
*   **CORS:** Переконатися, що CORS дозволяє доступ до цих ресурсів з веб-версії та мобільних клієнтів.
*   **Response Integrity:** Перевірити, що при запиті без токена повертаються коректні дані, а не помилка `401 Unauthorized` чи `403 Forbidden`.

## Пріоритет: Високий
**Причина:** Необхідно для коректного відображення контенту в мобільному застосунку та на веб-сайті для неавторизованих користувачів.
