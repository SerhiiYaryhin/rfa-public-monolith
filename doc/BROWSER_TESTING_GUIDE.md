# Інструкція по тестуванню публічної частини сайту через браузер

## Загальна інформація

Ця інструкція містить кроки для тестування публічної частини сайту RFA (Radio for All) через браузер. Публічна частина доступна без авторизації і містить наступні основні розділи:

- Головна сторінка
- Сторінки авторів та їхніх колонок
- Сторінки статей
- Подкасти
- Пости

## Попередні вимоги

- Веб-браузер (рекомендовано: Chrome, Firefox, Safari або Edge)
- Доступ до сервера, на якому розгорнуто додаток

## Основні сторінки для тестування

### 1. Головна сторінка

**Шлях:** `/` або `/home`

**Тестування:**
- Відкрийте головну сторінку у браузері
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображаються основні елементи інтерфейсу (меню, банери, медіа-контент)
- Перевірте, що всі посилання на головній сторінці працюють коректно

### 2. Сторінка авторів

**Шлях:** `/guest/authors`

**Тестування:**
- Відкрийте сторінку авторів
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається список авторів
- Перевірте, що можна перейти до колонки кожного автора за посиланням
- Перевірте, що зображення авторів відображаються коректно

### 3. Сторінка колонки автора

**Шлях:** `/guest/authors/{columnSlug}`

**Тестування:**
- Перейдіть на сторінку будь-якої колонки автора
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається інформація про автора та колонку
- Перевірте, що відображається список статей у цій колонці
- Перевірте, що можна перейти до кожної статті
- Перевірте, що ілюстрації до статей відображаються коректно

### 4. Сторінка статті

**Шлях:** `/guest/authors/article/{articleSlug}`

**Тестування:**
- Перейдіть на сторінку будь-якої статті
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається заголовок, дата публікації, кількість переглядів
- Перевірте, що відображається головна ілюстрація статті
- Перевірте, що відображається контент статті
- Перевірте, що відображається інформація про автора
- Перевірте, що відображається секція коментарів (якщо дозволено)
- Перевірте, що метадані Open Graph відображаються коректно (особливо og:image)

### 5. Сторінка всіх статей

**Шлях:** `/guest/authors/articles-all`

**Тестування:**
- Відкрийте сторінку всіх статей
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається список всіх статей
- Перевірте, що можна перейти до будь-якої статті
- Перевірте, що пагінація працює коректно (якщо статей багато)
- Перевірте, що ілюстрації до статей відображаються коректно

### 6. Сторінка подкастів

**Шлях:** `/podcast/all` або `/podcast/episode/{episodeId}`

**Тестування:**
- Відкрийте сторінку подкастів
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається список епізодів подкастів
- Перевірте, що можна перейти до будь-якого епізоду
- Перевірте, що на сторінці епізоду відображається аудіо-плеєр
- Перевірте, що відображається ілюстрація епізоду
- Перевірте, що метадані Open Graph відображаються коректно

### 7. Сторінка постів

**Шлях:** `/guest/postall` або `/post/postview/{postId}`

**Тестування:**
- Відкрийте сторінку всіх постів
- Перевірте, що сторінка завантажується без помилок
- Перевірте, що відображається список постів
- Перевірте, що можна перейти до будь-якого поста
- Перевірте, що на сторінці поста відображається весь контент
- Перевірте, що відображається головна ілюстрація поста
- Перевірте, що метадані Open Graph відображаються коректно

## Перевірка метаданих Open Graph

Для кожної публічної сторінки перевірте наступні елементи:

- Відкрийте інструменти розробника у браузері (F12)
- Перейдіть на вкладку Elements
- Знайдіть теги `<meta property="og:*">`
- Перевірте, що:
  - `og:title` містить правильний заголовок сторінки
  - `og:description` містить короткий опис контенту
  - `og:image` містить посилання на правильне зображення
  - `og:url` містить актуальний URL сторінки
  - `og:type` вказує на правильний тип контенту (article, website, music.song тощо)

## Перевірка через Facebook Sharing Debugger

Для кожної сторінки, яка має соціальну інтеграцію:

1. Відвідайте https://developers.facebook.com/tools/debug/
2. Введіть URL сторінки для тестування
3. Натисніть "Debug"
4. Перевірте:
   - Чи відображається правильне зображення
   - Чи відображається правильний заголовок
   - Чи відображається правильний опис
   - Чи немає помилок або попереджень

## Тестування адаптивності

1. Відкрийте будь-яку публічну сторінку
2. Використовуйте інструменти розробника для симуляції різних розмірів екрану (мобільний, планшет, десктоп)
3. Перевірте, що:
   - Елементи інтерфейсу коректно відображаються на всіх розмірах екрану
   - Контент добре читається
   - Постилання легко натискати на мобільних пристроях

## Звіт про помилки

Якщо ви знайшли будь-які помилки або неполадки під час тестування:

1. Запишіть точний шлях сторінки
2. Опишіть дії, які призвели до помилки
3. Зробіть скріншот, якщо можливо
4. Запишіть повідомлення про помилку (якщо є)
5. Надішліть інформацію розробникам
