**Дата та час звіту:** 09.07.2026 20:15 (EEST)  
**Версія інтеграції:** WebRTC V2  
**Основна технологія:** Janus Gateway (AudioBridge Plugin) + Spring Boot (RabbitMQ & WebSockets) + FFmpeg (Python Agent)

---

## 1. Загальний огляд архітектури (V2)

Поточна архітектура модуля побудована за схемою низької затримки (Low Latency) та високої масштабованості. Вона використовує плагін **Janus AudioBridge** для міксування аудіопотоків користувачів та зовнішнього радіоефіру в реальному часі.

### Ключові покращення версії V2 порівняно з V1:
* **Безпека:** `api_secret` та `admin_secret` більше не передаються на сторону клієнта (браузера). Усі чутливі запити до Janus проходять через Spring Boot бекенд.
* **Трансляція радіо (Inbound):** Замість некоректного використання `rtp_forward` для вхідного аудіо, реалізовано приєднання радіопотоку як **Plain RTP Participant** через створення персистентної сесії та хендлу на бекенді.
* **Фонове підтримання зв'язку (Heartbeat):** Додано Spring Scheduler, який кожні 20 секунд відправляє keepalive-запити для сесій активних Plain RTP стрімів, запобігаючи автоматичному відключенню з боку Janus.
* **Самовідновлення (Auto-healing):** При перезапуску Janus або виникненні мережевих збоїв, бекенд автоматично перестворює кімнату, перепідключає Plain RTP учасника, оновлює порти в базі даних та перезапускає FFmpeg-агента з новими параметрами.

## 2. Специфікація функцій трансляції та модерації

### 🎙️ А. Трансляція зовнішнього аудіопотоку (Радіо)
1. **Виділення портів:** Порт виділяється динамічно за допомогою `PortAllocationService`.
2. **Strict Source Port Validation:** Janus вимагає, щоб вхідні RTP пакети надходили з того самого порту, який вказано при приєднанні. Тому FFmpeg запускається з параметром `localport`:
   `rtp://janus.rfa:<janus_rtp_port>?localport=<free_db_port>&pkt_size=1200`
3. **Керування сесіями:** Сесії та хендли Plain RTP учасників зберігаються в БД `JanusLiveStream` (`janus_session_id`, `janus_handle_id`) та знищуються при виклику `/stop`.

### 🔄 Б. Переміщення користувачів між кімнатами (Move)
* Модератор може змінити кімнату для будь-якого WebRTC клієнта.
* Команда передається через WebSocket (SockJS + STOMP) канал: `/topic/webrtc.control.{userUuid}`.
* Клієнтський браузер отримує подію `{ "action": "switch_room", "targetRoomId": 900 }` і безшовно перепідключає WebRTC PeerConnection до нової кімнати Janus AudioBridge.

### 🔇 В. Керування мікрофонами відвідувачів (Mute / Unmute)
* Модератор може вимикати або вмикати звук будь-якому учаснику кімнати за його внутрішнім ID в Janus.
* Використовується Janus API `configure` запит із прапорцем `"muted": true/false` на стороні плагіна AudioBridge.

### ❌ Г. Вигнання відвідувачів (Kick)
* Модератор може примусово відключити учасника від кімнати.
* Бекенд надсилає в Janus запит `"request": "kick"` із зазначенням ID учасника.

### 📡 Д. Ретрансляція міксу кімнати назовні (RTP Forward)
* Модератор може налаштувати ретрансляцію загального аудіоміксу кімнати на будь-яку зовнішню IP-адресу та порт (наприклад, для ретрансляції у головну кімнату або на Icecast сервер).
* Бекенд викликає в Janus запит `rtp_forward` для поточної кімнати.

## 4. Специфікація REST API (v2)

Усі ендпоінти мають базовий префікс `/api/v1q/webrtc/stream`.

| Метод | Шлях | Параметри запиту | Опис |
| :--- | :--- | :--- | :--- |
| **POST** | `/start` | `stationId` (String) | Запуск трансляції радіостанції у Janus кімнату (Plain RTP) |
| **POST** | `/stop` | `stationId` (String) | Зупинка трансляції радіостанції та вивільнення ресурсів |
| **GET** | `/token` | - | Отримання токена авторизації користувача (UUID) |
| **GET** | `/rooms` | - | Отримання списку активних кімнат та учасників з Janus |
| **POST** | `/connectclienttoroom` | Тело JSON: `{ "roomid": Long }` | Підготовка підключення клієнта до кімнати (евакуація з попередньої кімнати) |
| **POST** | `/moderate/move` | `userUuid` (String), `targetRoomId` (Long) | Переміщення користувача між кімнатами Janus |
| **POST** | `/moderate/mute` | `roomId` (Long), `participantId` (Long), `muted` (boolean) | Вимкнення/увімкнення мікрофона учасника |
| **POST** | `/moderate/kick` | `roomId` (Long), `participantId` (Long) | Вигнання учасника з кімнати |
| **POST** | `/moderate/forward/start` | `roomId` (Long), `host` (String), `port` (Integer) | Запуск ретрансляції (RTP Forward) міксу кімнати назовні |
| **POST** | `/moderate/forward/stop` | `roomId` (Long), `streamId` (Long) | Зупинка ретрансляції (RTP Forward) |
| **GET** | `/ping` | - | Діагностика з'єднання бекенду з Janus Admin API |
