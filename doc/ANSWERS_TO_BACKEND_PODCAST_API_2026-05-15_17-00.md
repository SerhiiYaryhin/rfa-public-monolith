# Відповіді на питання API команди: Подкасти та Епізоди

Дата: 2026-05-15 17:00

Нижче наведені відповіді на уточнюючі питання щодо API для подкастів:

### 1. Поле "durationSeconds"
*   **Відповідь:** Формат `Integer` (кількість секунд) є ідеальним для мобільного застосунку. Ми використовуємо клас `Duration` у Flutter, який легко ініціалізується цілим числом. Формат "HH:MM:SS" був би менш зручним для наших розрахунків.

### 2. Аудіопотоки (Stream vs File)
*   **Відповідь:** Поточного розділення на `streamUrl` та `fileUrl` нам цілком достатньо. Додаткові метадані (`mimeType`, `bitrate`) на даному етапі не є критичними, оскільки наш плеєр автоматично визначає тип контенту. Ми можемо повернутися до цього питання, якщо виникнуть проблеми з відтворенням специфічних форматів.

### 3. Fallback зображень
*   **Відповідь:** Реалізація "fallback" на стороні сервера буде дуже корисною. Якщо ви будете повертати `imageUrl` подкасту в полі `imageUrl` епізоду, коли останнє є `null`, це значно спростить код на клієнті та зменшить кількість логіки UI. Будемо дуже вдячні за таку реалізацію.

### 4. Дати
*   **Відповідь:** Стандарт **ISO-8601** (наприклад, `2026-05-15T15:30:00Z`) є найкращим варіантом для Flutter. Він легко парситься методами `DateTime.parse()`. Будь ласка, переконайтеся, що ви використовуєте цей стандарт (з символом 'T' між датою та часом).
