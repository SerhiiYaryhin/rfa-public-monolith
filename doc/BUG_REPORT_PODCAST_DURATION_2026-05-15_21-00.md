# Звіт про помилку API: Формат поля durationSeconds (Podcasts)

Дата: 2026-05-15 21:00

## 1. Опис проблеми
При зверненні до ендпоінту `GET /api/v1/podcasts/{id}` сервер повертає помилку `500 Internal Server Error`.

## 2. Деталі помилки
Відповідь сервера:
```json
{
  "timestamp": "2026-05-15T18:53:43.736574807",
  "status": 500,
  "error": "Internal Server Error",
  "message": "For input string: \"00:08:26\"",
  "path": "/api/v1/podcasts/40cfd567-0b0e-4ea7-a28b-38411e91d780"
}
```

## 3. Причина
Згідно з нашою специфікацією, поле `durationSeconds` має передаватися як **Integer** (кількість секунд). Схоже, що на сервері відбувається спроба конвертації рядка формату "HH:MM:SS" у число, що призводить до `NumberFormatException` (For input string: "00:08:26").

## 4. Очікувана поведінка
Сервер має повертати тривалість як ціле число (кількість секунд), наприклад:
```json
"durationSeconds": 506
```

## 5. Прохання
Будь ласка, виправте логіку серіалізації на бекенді, щоб поле `durationSeconds` завжди передавалося як `Integer`, або надайте можливість нашому застосунку коректно отримувати тривалість.
