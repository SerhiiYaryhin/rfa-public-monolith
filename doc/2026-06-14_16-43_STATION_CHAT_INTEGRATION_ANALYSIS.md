# Аналіз інтеграції чат-кімнат з інтерфейсом радіостанцій для прямих ефірів
**Дата:** 14 червня 2026 р.
**Час:** 16:43
**Статус:** Технічний аналіз та пропозиції

Цей документ містить аналіз поточної реалізації та можливостей розширення функціоналу створення та керування чат-кімнатами безпосередньо з інтерфейсу керування радіостанцією.

## 1. Поточний стан (As-Is)

На даний момент у системі вже закладено базовий механізм зв'язку радіостанції з чат-кімнатою:
*   **Модель даних**: Сутність `Station` містить поле `roomuuid`, яке посилається на `MessageRoom`.
*   **Ручне створення**: В інтерфейсі керування станцією (`controlstation.html`) є блок "Чат та Прямий ефір". Якщо кімнати ще немає, відображається кнопка "Створити кімнату".
*   **Ручна активація**: Користувач може вручну "Відкрити ефір", що змінює статус `roomOnlineStatus` у чат-кімнаті. Це сигнал для системи, що в цій кімнаті зараз відбувається активне спілкування.

## 2. Можливості модернізації та створення кімнат

### 2.1. Автоматизація створення (Wizard Integration)
Замість того, щоб змушувати користувача натискати окрему кнопку після розгортання станції, створення чат-кімнати можна інтегрувати в:
1.  **Station Wizard**: На фінальному етапі створення станції система автоматично генерує `MessageRoom` з назвою станції.
2.  **Ansible Provisioning**: Як тільки плейбук успішно розгорнув Docker-контейнери станції, Java-сервіс автоматично створює кімнату.

### 2.2. Інтеграція з Прямим Ефіром (Live Detection)
Зараз "Відкрити ефір" — це суто адміністративна дія в інтерфейсі. Пропонується зробити її інтелектуальною:
*   **Icecast Status Sync**: Система може періодично опитувати статус Icecast-сервера станції. Як тільки з'являється активне джерело (source) на mount-пойнті, чат-кімната автоматично переходить у статус `Online`.
*   **Автоматичне сповіщення**: При активації ефіру система може автоматично надсилати повідомлення в загальний чат: *"Станція [Назва] вийшла в прямий ефір! Приєднуйтесь до обговорення: [Посилання]"*.

## 3. Технічна реалізація створення кімнати

Для реалізації створення кімнати безпосередньо "під ефір" пропонується:

1.  **API Endpoint**: Створити REST-метод `POST /api/station/{uuid}/room`, який буде:
    *   Перевіряти наявність кімнати.
    *   Створювати нову з типом `CHATROOM_TYPE_STATION`.
    *   Прив'язувати її до станції.
2.  **UI Enhancement**: 
    *   Додати кнопку "Швидкий старт ефіру + Чат", яка одним кліком перевіряє готовність інфраструктури та відкриває чат.
    *   Вбудувати міні-вікно чату прямо в сторінку керування станцією, щоб модератор міг бачити повідомлення слухачів, не залишаючи панель керування ефіром.

## 4. Висновок та рекомендації

Створення чат-кімнати з інтерфейсу радіостанції не тільки можливе, але й частково реалізоване. Для повноцінного функціоналу "Прямих ефірів" рекомендується:
1.  **Автоматизувати** процес створення кімнати при першому запуску станції.
2.  **Синхронізувати** статус чату з реальним потоком Icecast.
3.  **Покращити UI**, вбудувавши вікно повідомлень безпосередньо в дашборд станції.
