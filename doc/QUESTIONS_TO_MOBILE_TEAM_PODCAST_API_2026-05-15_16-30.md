Дата: 2026-05-15 16:30

1. **Поле "durationSeconds"**:
   - Наш бекенд зберігає тривалість треку (timetrack) як рядок. Для API я конвертував його в `Integer`. Чи гарантовано, що значення завжди буде цілим числом? Чи очікуєте ви інший формат (наприклад, "HH:MM:SS")?

2. **Аудіопотоки (Stream vs File)**:
   - Зараз ми маємо `streamUrl` (`/store/audio/{uuid}`) та `fileUrl` (`/store/content/{uuid}`). Чи достатньо цієї роздільної здатності для вашого плеєра, чи потрібно передавати додаткові метадані типу `mimeType` або `bitrate`?

3. **Fallback зображень**:
   - Ви згадували, що на стороні клієнта реалізуєте fallback `imageUrl` (якщо у епізоду немає — брати у подкасту). Чи потрібно нам реалізувати це на сервері (якщо `e.imageUrl` — null, автоматично підставляти `podcast.imageUrl`), щоб спростити вашу логіку?

4. **Дати**:
   - Зараз ми передаємо дату як `toString()`. Чи підходить вам цей формат (ISO-8601), чи потрібно застосувати специфічний DateTimeFormatter?
