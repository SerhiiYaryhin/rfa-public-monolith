# Walkthrough - Podcast Episode Deletion Restored
**Created: 2026-05-20 19:12**

We have resolved the silent thread termination and blank screen issue when deleting podcast episodes by addressing the Lombok circular reference trap and encapsulating the deletion logic inside a clean, transactional service wrapper.

## Changes Made

### 1. Fixed Lombok equals/hashCode Trap (StackOverflowError prevention)
- **`PodcastChannel.java`**: Added `@EqualsAndHashCode.Exclude` to `item` and `itunescategory` lists.
- **`PodcastItem.java`**: Added `@EqualsAndHashCode.Exclude` to the parent `chanel` reference.
- **`PodcastItunesCategory.java`**: Added `@EqualsAndHashCode.Exclude` to the parent `chanel` reference.
- *Reasoning*: These bidirectional fields previously generated recursive equals/hashCode methods. Calling `List.remove(episode)` triggered infinite equality checks, causing `StackOverflowError` and silent crashes. Excluding them prevents this safely.

### 2. Transactional & Safe Deletion Service Logic
- **`PodcastService.java`**: Imported `org.springframework.transaction.annotation.Transactional` and annotated `DeleteEpisode()`.
- Refactored `DeleteEpisode` to dissociate the episode from the channel, save the updated channel, and then delete the episode from the repository in a single transaction:
  ```java
  @Transactional
  public void DeleteEpisode(PodcastItem episode, boolean deleteFile) {
      if (deleteFile && episode.getEnclosurestore() != null) {
          storeService.DeleteInStore(episode.getEnclosurestore());
      }
      PodcastChannel channel = episode.getChanel();
      if (channel != null) {
          channel.getItem().remove(episode);
          episode.setChanel(null);
          chanelRepository.save(channel);
      }
      episodeRepository.delete(episode);
  }
  ```

### 3. Controller Simplification
- **`EpisodeEditController.java`**: Refactored the `deleteEpisode` endpoint to delegate the entire database/filesystem deletion sequence to the simplified, transaction-safe service method. This keeps transaction boundaries clean.
