# Архітектура та структура проекту RFA

Цей документ описує склад та технічну структуру проекту **Radio For All (RFA)** до рівня ключових сервісів та їх функцій.

## 1. Загальний огляд
Проект є монолітною Spring Boot програмою, що використовує **Java 21** та **Spring Boot 3.5.4**. Система реалізує повний цикл керування медіа-контентом: від завантаження та обробки до публікації та трансляції (через RSS/Podcast).

## 2. Модулі бекенду

### 2.1. Система безпеки (Security)
Керує авторизацією та розмежуванням прав на основі ролей.
- **Пакет:** `media.toloka.rfa.security`
- **Ключові класи:**
    - `SecurityConfig`: Конфігурація ланцюжка фільтрів, налаштування доступів до ендпоїнтів.
    - `Users`, `Roles`: Сутності користувачів та їх повноважень.

### 2.2. Клієнтська логіка (Client Service)
Керує профілями користувачів, адресами та специфічними даними клієнтів.
- **Клас:** `ClientService.java`
- **Основні функції:**
    - `GetCurrentUser()`: Повертає поточного авторизованого користувача.
    - `GetClientDetailByUser(Users user)`: Отримує розширені дані клієнта (баланс, контракти, історія).
    - `checkRole(Users user, ERole role)`: Перевірка наявності конкретної ролі у користувача.
    - `CreateClientsDetail(...)`: Створення нового профілю клієнта при реєстрації.

### 2.3. Сховище та файлова система (Store Service)
Універсальна система збереження та індексації файлів.
- **Клас:** `StoreService.java`
- **Основні функції:**
    - `PutFileToStore(...)`: Збереження бінарних даних, генерація UUID, реєстрація в БД.
    - `GetStorePage(...)`: Повернення сторінки файлів з пагінацією.
    - `GetAllPictures(...)`: Фільтрація зображень для вибору обкладинок.
- **Обробка:** `AdminPrepare.java` виконує автоматичну конвертацію в MP3 за допомогою FFmpeg.

### 2.4. Авторська колонка та статті (Author Module)
- **Класи:** `AuthorService`, `AuthorArticleService`
- **Основні функції:**
    - `approveRequest(String uuid)`: Модерація запиту на авторство та автоматичне створення персональної колонки.
    - `saveArticle(AuthorArticle)`: Збереження статей, що приходять у форматі JSON з Editor.js.
    - `getPublishedArticlesByColumn(...)`: Вибірка статей для публічного перегляду.

### 2.5. Подкасти та RSS (Podcast Module)
Генерація фідів та керування епізодами.
- **Клас:** `PodcastService.java`
- **Основні функції:**
    - `SavePodcast(PodcastChannel)`: Реєстрація каналу подкастів.
    - `generateRss(String uuid)`: Динамічна генерація XML-файлу для iTunes.
    - `DeleteEpisode(..., boolean deleteFile)`: Видалення епізоду з можливістю фізичного видалення аудіофайлу.

### 2.6. Адміністрування (Admin Service)
Глобальне керування контентом та користувачами.
- **Клас:** `AdminService.java`
- **Основні функції:**
    - `getUsersPage(...)`: Розумна пагінація користувачів з фільтрацією за станом документів/адрес.
    - `GetNotApruvePosts()`: Вибірка контенту, що очікує модерації.
    - `SaveTrack(Track)`: Схвалення та публікація аудіо-треків.

## 3. Інтеграції та RPC
Проект взаємодіє із зовнішніми сервісами (TTS, STT) через RabbitMQ.
- **Клас:** `RPCSpeachService.java` — відправка завдань на синтез голосу.
- **Клас:** `STTBackServerService.java` — обробка результатів розпізнавання мови.

## 4. База даних
Використовується **PostgreSQL**. Основні таблиці:
- `users`, `roles` — безпека.
- `clientdetail`, `clientaddress` — профілі та юридична інформація.
- `store` — метадані файлів.
- `author_columns`, `author_articles` — контент авторів.
- `podcast_channel`, `podcast_item` — структура подкастів.
