# Документація: Методика тестування Ansible-інтеграції
**Дата:** 12 червня 2026 р.
**Статус:** Робоча інструкція

Цей документ описує методику тестування нових сервісів керування радіостанціями через Ansible за допомогою тестового контролера `AnsibleTestController`.

## 1. Опис тестового контролера

Контролер розташований за шляхом: `media.toloka.rfa.ansible.AnsibleTestController`.
Він надає REST API для ручного запуску інфраструктурних операцій без необхідності інтеграції в основний інтерфейс адміністратора.

### Базовий URL: `http://localhost:3080/api/test/ansible`

### Доступні Endpoint-и:

| Метод | Шлях | Параметри | Опис |
| :--- | :--- | :--- | :--- |
| `GET` | `/create` | `ip`, `port` | Повне розгортання (FS, DB, MQ, Docker, Nginx) |
| `GET` | `/start` | `ip` | Запуск контейнерів (`docker-compose up`) |
| `GET` | `/stop` | `ip` | Зупинка контейнерів (`docker-compose down`) |
| `GET` | `/delete` | `ip` | Каскадне видалення всіх ресурсів та дискових квот |

## 2. Методика тестування

Для проведення успішного тестування рекомендується дотримуватися наступної послідовності дій.

### Крок 1: Підготовка оточення
1. Переконайтеся, що на сервері RFA встановлено `ansible`.
2. Перевірте SSH-доступ до цільового сервера (за замовчуванням `192.168.1.50`) під користувачем `rfa-worker`.
3. Запустіть додаток RFA.

### Крок 2: Тест розгортання (Provisioning)
Виконайте запит:
```bash
curl "http://localhost:3080/api/test/ansible/create?ip=192.168.1.50&port=8085"
```
**Що перевірити:**
*   У логах додатка має з'явитися вивід Ansible плейбука.
*   На цільовому сервері має з'явитися файл-образ: `ls -lh /Clients/test-client-1/test-station-1/storage.img`.
*   Має бути створена база даних `test_db` та vhost у RabbitMQ `/test_vhost`.
*   Контейнери мають бути в статусі `Up`: `docker ps`.

### Крок 3: Тест керування (Control)
Зупиніть станцію:
```bash
curl "http://localhost:3080/api/test/ansible/stop?ip=192.168.1.50"
```
**Що перевірити:** Контейнери станції зупинені, але дані в БД та на диску збережені.

Запустіть станцію знову:
```bash
curl "http://localhost:3080/api/test/ansible/start?ip=192.168.1.50"
```

### Крок 4: Тест видалення (Cleanup)
Виконайте каскадне видалення:
```bash
curl "http://localhost:3080/api/test/ansible/delete?ip=192.168.1.50"
```
**Що перевірити:**
*   Контейнери видалені.
*   Каталог станції та файл-образ `.img` видалені.
*   Запис у `/etc/fstab` очищено.
*   База даних та користувач у PostgreSQL видалені.
*   Vhost у RabbitMQ видалено.

## 3. Аналіз логів

Усі дії Ansible логуються з префіксами:
*   `[Ansible Create]` — створення.
*   `[Ansible Control]` — запуск/зупинка.
*   `[Ansible Delete]` — видалення.

У разі помилки Ansible (exit code != 0), лог зафіксує конкретний Task, який провалився, що полегшує діагностику.
